# Embedded Systems Portfolio

Selected firmware, systems software, and validation projects.

| Project | Focus |
| --- | --- |
| [MAVLink Telemetry Collector](mavlink-telemetry/) | Python, flight telemetry, stale-data handling, unit tests |
| [STM32 Tone Player and Recorder](stm32-tone-recorder/) | Bare-metal C, GPIO, software I2C, external EEPROM |
| [MiniHawk VTOL Simulation Validation](minihawk-sitl-validation/) | ArduPilot SITL, Gazebo, telemetry analysis, reproducible trial comparison |
| [STM32 Peripheral Examples](stm32-peripheral-examples/) | Keypad and LCD calculator, ADC/PWM, timer interrupts |
| [32-bit RISC-V Processor](riscv-processor/) | Verilog, datapath and control, Vivado simulation |

The MAVLink collector and MiniHawk case study come from UCI senior design. The STM32 examples and RISC-V processor are course projects.
